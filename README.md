# PUYO PLACE

「ブロックブラストの自由配置 + ぷよぷよの同色消去 + 重力なし」の、一人用ブラウザパズルです。スマートフォンの縦画面とPCのマウス操作に対応しています。

## 起動

Node.js 22以上を用意し、このディレクトリで実行してください。ゲームの起動にパッケージのインストールやビルドは不要です。

```sh
npm start
```

ブラウザで http://localhost:4173 を開きます。同じWi-Fi上のスマートフォンからは `http://PCのLANアドレス:4173` でアクセスできます（PC側のネットワーク設定が接続を許可している場合）。`PORT` 環境変数でポートを変更できます。

静的配信の場合は `index.html`、`style.css`、`app.js`、`game.js` の4ファイルを同じ場所に置くだけです。GitHub Pagesなどのサブディレクトリ配信にも対応しています。ES Modulesを使うため、HTMLのダブルクリックではなくHTTPサーバー経由で開いてください。

## ルール

- 8×8の盤面、4色。上下または左右につながる2マスのピースを使います。同色・異色の組み合わせが出現します。
- 手元は3個。好きな順番に使え、全て使うと新しい3個を補充します。
- 両方のマスが盤面内の空きなら配置できます。支えや上からの経路は不要で、囲まれた空きにも直接置けます。
- 配置後、盤面全体を調べます。同色が上下左右に4個以上つながると、グループ全体を同時に消します。斜めや、異なる色で埋まった行・列は消去条件に含めません。
- ピースの片方だけが消えることもあります。残りは同じマスに留まります。
- **配置後も消去後も重力・左右への圧縮・落下による連鎖は一切ありません。** 消去対象だけを空きにし、それ以外の座標は変更しません。
- 消したブロック1個につき10点。同時消しへの追加倍率はありません。
- 消去と必要な補充が済んだ後、残る全ピースの4方向を調べ、どれも置けなければゲームオーバーです。
- 時間制限はありません。ベストスコアのみブラウザに保存します。ストレージが使用できなくても遊べます。

## 操作

- **ドラッグ**：手元から盤面へ移動して離します。半透明の候補が配置先です。タッチでは指で隠れないよう候補を指の少し上に表示します。
- **配置不可**：赤い破線と×で表示します。そこで離しても手札や盤面は変わりません。操作中断でも手元に戻ります。
- **タップ／クリック**：ピースを選択 → 必要なら回転 → 盤面で押して離して配置できます。
- **回転**：選択中のピースを90度時計回りに回転します。180度・270度では色の順番も回転します。
- **キーボード**：`1`〜`3`で選択、`R`で回転。Tabで盤面に移動し、矢印キーで候補を移動、Enter／Spaceで配置、Escでドラッグ・プレビューをキャンセルします。
- **リスタート**：確認画面からやり直せます。ベストスコアは残ります。

色に加えて ●・◆・▲・■ の記号で区別できます。演出は対象マス内の拡縮・明滅のみで、残ったブロックの位置は動きません。OSの「視差効果を減らす」設定も尊重します。

## 設定と構成

`game.js` の `CONFIG` に盤面サイズ・色数・手札数・消去に必要な数・ブロックごとの得点をまとめています。色数を4より増やす場合は `app.js` の色名・記号と `style.css` の配色を追加してください。ルール設定を変更した場合は説明文も合わせて更新してください。

| ファイル                | 役割                                                 |
| ----------------------- | ---------------------------------------------------- |
| `game.js`               | 副作用のない配置・接続・消去・補充・終了判定         |
| `app.js`                | Pointer Eventsによる入力、描画、短い演出、ダイアログ |
| `style.css`             | スマホ優先の画面と配色                               |
| `server.js`             | 外部依存のない開発用HTTPサーバー                     |
| `tests/game.test.js`    | ルールと座標不変の回帰テスト                         |
| `tests/ui/game.spec.js` | PC・モバイルのブラウザ操作テスト                     |

消去エンジンは一度だけ接続グループを探索し、該当セルを `null` にします。重力処理や連鎖処理はありません。UIの演出中は配置をロックし、リスタート時は以前の演出処理を無効にします。

## 検証

```sh
npm test
```

ルールの14テストをNode.jsの標準テストランナーで実行します。

```sh
npm ci
npx playwright install chromium
npm run test:ui
```

PCとモバイルのUIテストを実行します。対応する入力方式だけを各環境で実行するため、全16ケース中13件を実行し3件をスキップします。既存のEdgeを使う場合はPowerShellで `$env:PLAYWRIGHT_CHANNEL='msedge'` を設定して実行できます。テスト実行時に開発サーバーも自動起動します。

配置境界、衝突、囲まれた空き、L字・四角形・5個以上・同時消去、片方だけの消去、残存ブロックの座標維持、任意順での使用、補充、回転を含めた終了判定を検証しています。ブラウザ側ではドラッグ・タッチ中断・スコア・リスタート・キーボード・ゲームオーバー・スマホの横はみ出しを確認します。
